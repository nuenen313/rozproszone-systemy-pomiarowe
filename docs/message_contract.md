### Opis struktury topiców
Ogólna struktura topiców wygląda następująco:

```
lab/<group_id>/<device_id>/<sensor>
```
Dla topiców statusowych przewidziano osobną strukturę, tj.:
```
lab/<group_id>/<device_id>/status
```
